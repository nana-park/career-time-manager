# Career Time Manager

지원 마감, 면접 준비, 개인 일정과 이월 작업을 실제 가용시간 안에서 실행 가능한 계획으로 바꾸는 Codex 스킬입니다.

## 기능과 입력·출력

- 입력: 오늘의 집중 가능 시간, 지원·과제·면접 마감, 선행 작업, 개인 일정의 busy 구간, 전날 미완료 작업. 연결된 Google Calendar와 Notion은 필요한 범위에서만 조회합니다. 연결이 없으면 사용자가 정보를 제공해야 합니다.
- 처리: 이동·식사·회복·전환 시간을 반영하고, 마감 손실·전형 기여도·의존 관계·작업 구간 적합성에 따라 우선순위를 정합니다. 큰 작업을 결과와 종료 조건이 있는 단위로 나누고 일정 변화에 맞춰 재계획합니다.
- 출력: 실제 가용시간, 필수 작업 1~3개와 선정 이유, 예상시간과 완료 기준, 선택 작업, 이월 이유·재개 조건, 가까운 마감과 충돌입니다.

## 설치

이 저장소 루트가 스킬 폴더입니다. 프로젝트의 `.agents/skills/career-time-manager`에 저장소를 복제하거나 전체 내용을 복사하세요. 이미 설치된 폴더는 덮어쓰기 전에 비교하세요.

```sh
git clone https://github.com/nana-park/career-time-manager.git .agents/skills/career-time-manager
```

Codex에서 해당 작업공간을 열고 `SKILL.md`가 로드되는지 확인합니다. 서비스 연결과 접근 권한은 별도로 준비해야 하며 이 저장소는 인증 정보를 포함하지 않습니다.

## 사용 예

```text
$career-time-manager 오늘 집중 가능 시간은 3시간이고 내일 지원 마감,
금요일 면접이 있어. 지원서 검토 90분과 면접 경험 정리를
완료 기준이 있는 작업으로 나눠 오늘 계획을 짜줘.
```

```text
$career-time-manager 개인 일정으로 1시간이 줄었어.
남은 시간에 맞춰 범위를 줄이고 내일 첫 행동까지 정리해줘.
```

## 범위와 한계

독립 실행 프로그램이나 예약 서비스가 아니라 Codex의 판단·실행 지침입니다. 시간 추정과 우선순위는 입력의 정확성에 의존하며 채용 결과를 보장하지 않습니다. 지원 현황 관리나 지원서·면접 전문 판단은 별도 역할입니다. 사용자의 명시적 요청 없이 Calendar 이벤트나 Notion 항목을 생성·수정하지 않습니다. 개인 일정 상세와 지원 기록을 이 공개 저장소에 저장하지 마세요.
